# 🚗 Los Santos Auto — Loja de Carros Usados Online

> Projeto acadêmico de e-commerce desenvolvido em React, inspirado no universo de GTA V.

---

## 📋 Sobre o Projeto

O **Los Santos Auto** é uma aplicação web de venda de carros usados online, desenvolvida como projeto da disciplina de Desenvolvimento Web. A interface foi inspirada na estética urbana e dark do jogo GTA V, com identidade visual neon, tipografia de impacto e experiência de navegação fluida.

O site simula uma concessionária fictícia localizada em "Los Santos", onde o usuário pode explorar um catálogo de veículos, filtrar por categoria, visualizar detalhes de cada carro e adicionar itens a um carrinho de reservas.

---

## 🖥️ Páginas

| Página | Descrição |
|---|---|
| **Home** | Apresentação da loja com hero section, estatísticas e veículos em destaque |
| **Catálogo** | Listagem dinâmica de todos os veículos com filtros e busca |
| **Detalhes** | Página individual de cada carro com especificações completas |
| **Sobre** | História da empresa, valores e equipe |
| **Contato** | Formulário de contato, endereço e horário de funcionamento |
| **Política de Privacidade** | Termos de uso de dados em conformidade com a LGPD |

---

## ⚙️ Funcionalidades

- 🔍 **Busca** por nome ou marca do veículo
- 🗂️ **Filtro** por categoria (Hipercarro, Superesportivo, Esportivo, Sedan)
- ↕️ **Ordenação** por menor preço, maior preço ou potência
- 🛒 **Carrinho de reservas** com adicionar, remover e atualizar quantidade
- 📊 **Resumo do pedido** com subtotal por item e total geral
- 📱 **Layout responsivo** para desktop e mobile
- 🎨 **Tema dark** com efeitos neon e animações suaves

---

## 🛠️ Tecnologias Utilizadas

- [React](https://react.dev/) — biblioteca principal de UI
- [Vite](https://vitejs.dev/) — bundler e servidor de desenvolvimento
- **CSS-in-JS** — estilização via objeto de estilo inline e tag `<style>`
- **Google Fonts** — fontes *Bebas Neue* e *Barlow*
- **JSON** — fonte de dados dos produtos (`cars.json`)

## 🚀 Como Rodar Localmente

**Pré-requisito:** ter o [Node.js](https://nodejs.org) instalado.

```bash
# 1. Clone o repositório
git clone https://github.com/seu-usuario/los-santos-auto.git
cd los-santos-auto

# 2. Instale as dependências
npm install

# 3. Inicie o servidor de desenvolvimento
npm run dev
```

Acesse em: **http://localhost:5173**
